# 算法 04 · 树的层序遍历与堆的 Top-K

> 目标：区分搜索顺序与元素优先级；把 C++ 所有权用于算法实现。
> 实现：[level_order / kth_largest](../../algorithms/algorithms.h)；测试：`algorithm_tests 4`。

## 1. 二叉树层序遍历

给定二叉树根，按从上到下、每层从左到右返回节点值。空树返回空列表。根 3、左右孩子 9 和 20、20 的孩子为 15 和 7，结果为 `[[3],[9,20],[15,7]]`。

深度优先递归可以按深度收集节点；本章使用队列 BFS，让待处理节点自然保持层次顺序。每轮先保存 `width=q.size()`，恰好弹出 width 个节点，将孩子依次加入队尾，然后结束这一层。

不变量：每轮开始，队列恰好存着当前层节点，按从左到右排列。本轮处理完，队列只剩按顺序加入的下一层节点。不能把 for 条件写成随时变化的 q.size()，因为入队孩子会改变大小，层边界就被破坏。

```cpp
const auto width = q.size();
for (std::size_t i = 0; i < width; ++i) {
    const TreeNode* node = q.front(); q.pop();
    level.push_back(node->value);
    if (node->left) q.push(node->left.get());
    if (node->right) q.push(node->right.get());
}
```

参考树用 unique_ptr 拥有孩子，队列用 `const TreeNode*` 临时观察。遍历不转移所有权，调用期间树必须存活并且不被其他线程无保护地修改；“只读函数”不意味着可以和写线程任意并发。

每个节点入队出队一次，时间 O(n)；队列峰值 O(w)，w 为最大层宽，最坏 O(n)；返回值占 O(n)。极深链状树的递归 DFS 以及递归所有权析构还可能受调用栈限制，本实现不是无限深树的内存回收方案。

## 2. 第 k 大元素

输入非空整数数组和从 1 开始的 k，返回排序后第 k 大的值，重复值各占一个名次。`[3,2,3,1,2,4,5,5,6]`、k=4 的答案是 4。k=0 或 k>n 非法。

排序后访问最直观，O(n log n)。如果只关心 k 个最大值，维护**大小不超过 k 的最小堆**：读入一个值就加入，超过 k 时弹出最小值。扫完后堆顶是保留下来的 k 个最大值中最小的，也就是第 k 大。

```cpp
std::priority_queue<int, std::vector<int>, std::greater<int>> heap;
for (int x : a) {
    heap.push(x);
    if (heap.size() > k) heap.pop();
}
return heap.top();
```

`std::priority_queue<int>` 默认最大堆；本题需要反过来，让最容易被淘汰的那个值在顶端。不要因为题目有“大”就选最大堆。

不变量：处理前 i 个元素后，堆保存其中最大的 min(i,k) 个，按多重集合计数。加入新元素后删除当前最小值，恰好保留下一轮需要的集合，因此归纳成立。

时间写作 O(n log(k+1)) 可覆盖 k=1，常简写 O(n log k)；额外空间 O(k)。Quickselect 可讨论平均 O(n)、最坏 O(n²)，本章不提供该实现，也不把平均界误称为保证。

## 3. 从算法到工程

数据流不断到来时，大小 k 的堆不必存完整输入；而排序需要整批数据。这是选型理由，不仅是复杂度表。若题目改成返回所有 Top-K，应规定输出是否排序、是否去重和同值如何计数。

树层序和 Top-K 都使用“队列”，但语义不同：FIFO 保留发现顺序，优先队列按优先级调度，替换后可能完全改变算法含义。

## 练习与参考思路

1. 将层序遍历改成每层求平均值。**提示**：保持层边界，累加使用更宽类型，避免先用 int 求和再转 double。
2. 返回每层最右节点。**参考**：记录当前固定 width 中最后处理的节点；不是看到右孩子就立即输出。
3. 数据流中 k 暂未满足时返回什么？**参考**：将接口设计为 optional；少于 k 个输入没有第 k 大。
4. 为树测试单节点、只有左孩子的链和重复值。**验收**：空树与层边界明确；节点重复值不影响访问每个节点一次。
